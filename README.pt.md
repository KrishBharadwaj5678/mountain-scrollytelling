<p align="center">

## <img src="https://github.com/KrishBharadwaj5678/scroll-scrubbing/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| --- | --- |
| 🖱️ Animação controlada pela rolagem | Controle a animação naturalmente através da rolagem |
| 🎞️ Renderização quadro a quadro | Transição suave entre os quadros para criar um efeito cinematográfico |
| ⚡ GSAP & ScrollTrigger | Animações suaves e sincronizadas com o uso do GSAP |
| 🔄 Transições suaves | Transições fluidas sincronizadas com o progresso da rolagem |
| 📱 Design responsivo | Otimizado para uma experiência suave em diferentes tamanhos de tela |
