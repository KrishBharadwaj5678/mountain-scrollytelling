## <img src="https://github.com/KrishBharadwaj5678/scroll-scrubbing/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| --- | --- |
| 🖱️ Анимация при прокрутке | Естественное управление анимацией с помощью прокрутки |
| 🎞️ Покадровый рендеринг | Плавное переключение между кадрами для создания кинематографического эффекта |
| ⚡ GSAP и ScrollTrigger | Плавные синхронизированные анимации с использованием GSAP |
| 🔄 Плавные переходы | Плавные переходы, синхронизированные с прогрессом прокрутки |
| 📱 Адаптивный дизайн | Оптимизировано для плавной работы на экранах разных размеров |
