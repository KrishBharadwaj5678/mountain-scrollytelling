## <img src="https://github.com/KrishBharadwaj5678/scroll-scrubbing/raw/main/assets/readme/features.gif" width="35"/> 特徴

| 特徴 | 説明 |
| --- | --- |
| 🖱️ スクロール駆動アニメーション | スクロール操作によって自然にアニメーションを制御 |
| 🎞️ フレーム単位のレンダリング | フレーム間をシームレスに切り替え、シネマティックな効果を実現 |
| ⚡ GSAP & ScrollTrigger | GSAPによる滑らかで同期されたアニメーション |
| 🔄 スムーズなトランジション | スクロールの進行度と同期した滑らかな切り替え |
| 📱 レスポンシブデザイン | さまざまな画面サイズで快適に動作するよう最適化 |

## <img src="https://github.com/KrishBharadwaj5678/scroll-scrubbing/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/scroll-scrubbing.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd scroll-scrubbing
```

### 3️⃣ ブラウザで開く

`index.html` をブラウザで開くだけで使用できます。
