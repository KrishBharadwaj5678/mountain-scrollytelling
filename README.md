## <img src="https://github.com/KrishBharadwaj5678/scroll-scrubbing/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature | Description |
| --- | --- |
| 🖱️ Scroll-Driven Animation | Control the animation naturally through scrolling |
| 🎞️ Frame-by-Frame Rendering | Seamlessly transition between frames for a cinematic effect |
| ⚡ GSAP & ScrollTrigger | Smooth, synchronized animations powered by GSAP |
| 🔄 Smooth Transitions | Enjoy fluid transitions synchronized with scroll progress |
| 📱 Responsive Design | Optimized for a smooth experience across different screen sizes |
